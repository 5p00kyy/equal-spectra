# Corrections, earlier results and useful criticism

The most useful contribution may be a reference showing that this result is already known. Please use [Issues](https://github.com/5p00kyy/equal-spectra/issues) for:

- Earlier literature, with the exact theorem or example and a stable citation.
- A gap in an argument, with the hypothesis or step that fails.
- A reproducible calculation or interface bug, including sensor deletions, block count, per-sensor failure probability and browser.
- An explanation that makes the phenomenon clearer without overstating the result.

Please distinguish correctness, originality and practical usefulness. This project claims no human peer review, hardware validation or proof-assistant formalization. AI involvement is disclosed in the note and README.

To check mathematical code, use Node22+ and run `npm test` and `npm run verify`. No package installation is needed. The site uses static HTML, CSS and browser-native JavaScript.

No broad rewrite or new dependency is needed to report a useful correction. Discuss substantial changes before undertaking them. Never submit credentials, private datasets or material you lack permission to share.
