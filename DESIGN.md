# Design intent

A new interactive mathematical explainer, not a startup landing page. The visitor should first see the phenomenon, then cause it themselves, then inspect the proof and reproduce the numbers.

## Direction

Paper meets instrument: warm ivory editorial canvas, graphite experimental bench, blue A and vermilion B. Large serif/sans hierarchy with monospaced measured quantities. The diagram and plotted data are original assets generated from the actual mathematics, not decorative scientific-looking imagery. System fonts, no external assets or tracking.

The existing research note supplies the retained content: exact A/B sets; protected distances 1..5; pair dependencies; complete spectral equality; correct deterministic and probabilistic distinctions; absolute risks; citations; AI provenance; originality unresolved.

## Acceptance

A visitor can remove any sensor, switch protected distance, restore the experiment, and reproduce the single-deletion example. The risk explorer recomputes from the exact failure distribution, rather than treating lag events as independent. Desktop and narrow mobile must preserve the controls, labels and data. Semantic controls, keyboard focus, non-colour status labels and reduced-motion behavior are required.

Functional tests do not replace visual review. The release refinement retains this language and adds a dependency schematic with true position labels, an exact complete distance histogram, readable surviving-pair lists and stronger non-colour sensor states. The owner authorized public release after the initial local preview.
